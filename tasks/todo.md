### 驗收與設計
- 完成需求 → 創作包 → 編輯／版本 → Suno 填寫 → 手動下載後匯入 → 歌曲封面匯出。
- 深墨藍與青綠配色，白色編輯頁與曲目側欄，直接顯示操作介面。
- Node 22 標準庫、原生 ES modules，不依賴 npm 安裝；IndexedDB 存本機資料，完整備份可攜出。
- AI 金鑰只在頁面記憶體，Gemini 為選用；未設金鑰提供複製 Prompt／貼回 JSON，範例明確標示。
- 子代理僅研究與審查；主代理統一編輯。本次不部署、不訂閱、不代生成或扣 Suno 點數。

### 風險與復原
- 中風險：創作文字外送 AI、本機持久化、擴充套件欄位寫入。
- 伺服器僅 loopback，固定官方 AI 端點，限制同源 JSON 與大小，不記錄金鑰；不傳音檔給 AI。
- 版本可還原，備份匯入新增專案；擴充套件僅使用者操作填寫，不按生成，欄位歧義時停下。
- 可停止本機伺服器／停用套件；透過備份復原資料。
